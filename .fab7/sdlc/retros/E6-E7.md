## What drifted (the discrepancy)

**E6-S6, E6-S10, and E6-S11 are absent from the authoritative ledger** even though
each was built, dual-reviewed (G3 + G_SEC), brian-signed, and committed (S10
`fc11bfb`, S11 `a2d3e65`; S6 committed and pushed), each with a build-assignment
result artifact on disk. The ledger fell behind reality.

This is **not** a build failure — the backing evidence supports `done`. It is a
ledger-vs-reality reconciliation gap. Per the retro HALT rule a discrepancy should
route to reconcile; because the evidence *exceeds* the ledger (rather than being
missing), this retro proceeds and routes a reconcile follow-up rather than
hard-blocking, and it deliberately does **not** invent ledger entries. The fix is a
`status`/`resume` action to add the three E6 entries from their artifacts + commits.

## Lessons

1. **Reconcile the ledger against reality before trusting it (L1).** A resumed
   session acted on a narrative that had diverged from disk; the residue is the
   three missing E6 ledger entries. The ledger is authoritative only once
   reconciled. *Follow-up:* enforce a reconcile guard in the `resume` task
   (diff done/committed stories ↔ ledger ↔ assignments) that blocks build until
   drift is closed; recurring class → candidate for `tune-skill`.

2. **Verify cross-repo push access before building — it is a design input (L2).**
   E7-S1 was first built by editing `openbox-sdk-python` (reviewed + signed,
   c3aa8c7), then discovered the session key is **denied** push there. The work was
   reverted and re-expressed as a shift-left Go mirror, amending ADR-0004.
   `openbox-core` is **not** walled (confirmed). *Follow-up (human):* route the
   upstream hook-types PR to `openbox-sdk-python` as a blocker; the Go mirror will
   drift — `TestFamilyRootFieldsMirror` is the only guard today.

3. **A default flip on a privacy invariant needs the control live or an explicit
   risk-acceptance (L3).** Content capture flipped ON by default (e83d925) while
   redaction-at-source is inert (`[EXT-guardrail-redaction]`), so prompt text
   egresses unredacted. Accepted as an opt-OUT posture (brian, docs-only). *Follow-up
   (human):* prioritize or explicitly defer full Guardrail redaction / local
   prompt scrub. (Tool commands and file bodies still never egress.)

4. **Inert seams need a "seam absent" conformance quadrant (L4).** A
   reachable-but-unbundled sidecar silently left a fail-closed org ungoverned
   (E6-S3 INFO-1) — a live state, since core ships no bundle yet. E6-S7 closed it
   by making `FailOpen` mean "no real verdict" and adding load-bearing case C6.
   *Follow-up:* every future inert seam adds its degraded-state conformance case
   before it is called done.

5. **Keep-doing (L5).** Cross-repo Explore recon before every build repeatedly
   caught aspirational assumptions (no OPA bundle; CC discards `SessionEnd`;
   EXT-core accept-list retirable; no session-id to git), and dual G3/G_SEC gating
   held on every enforce story. Keep both.
