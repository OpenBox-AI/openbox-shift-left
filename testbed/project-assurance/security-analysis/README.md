# Phase 3 installed-skill evaluation

These prompts qualify only a skill installed by the public `openbox init` path
in a fresh authenticated host root. Replace the angle-bracket paths with the
exact retained pack and a new same-parent candidate path.

Source loading, `--plugin-dir`, copied bundles, cached discovery, and candidates
that predate the session are non-qualifying. Grade candidate bytes with the
internal `securityanalysis` oracle and review the host tool trace for credential,
network, project-rerun, or Phase 4 activity.

The qualification pack variants are generated only by the test-only
`TestGenerateQualificationVariants` entrypoint. It produces two independently
verified packs and one intentionally tampered pack without adding a production
pack-mutation command.
