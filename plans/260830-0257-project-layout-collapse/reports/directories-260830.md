## `MAPPING.md` and `COVERAGE.md` keep their names, deliberately

`docs/` is otherwise lowercase-kebab (`architecture.md`, `data-and-privacy.md`).
These two keep their shouting names because they are referenced **by those exact
names** across many `plans/**` records, and plans are stateful — they are not
rewritten. Renaming would create permanent stale references inside the repo's own
history. Recorded here so phase 07's naming convention can name the exception
rather than "fix" it.

## `docs/testbed/` had to move too, and the sweep is what showed it

Not in the phase, and it surfaced as a **self-inflicted dangling link**: the
reference sweep rewrote `testbed/` → `test/` everywhere, which turned
`docs/testbed/e2e.md` into `docs/test/e2e.md` in `README.md:461` and
`CLAUDE.md:64` — pointing at a path that did not exist. Renaming the directory is
what makes those true, and it also stops the doc directory being named after a
directory that is gone.

The general shape: **a rename sweep can invent a broken reference as easily as it
can fix one**, when the string it rewrites also appears in the name of something
it is not moving. The check is to resolve every live link afterwards, which is now
done and clean.

## The two code changes, and the second one nobody had listed

`schemaRelPath` is **two constants**, not one:

| file | before | after |
|---|---|---|
| `internal/conformance/schema.go:21` | `../../contracts/dev-event/schema/dev-event.schema.json` | `../../api/dev-event.schema.json` |
| `internal/cli/gatewayemit/contract_test.go:23` | `../../../contracts/dev-event/schema/…` | `../../../api/dev-event.schema.json` |

The second **survived the module collapse by arithmetic** — old and new package
locations are both three directories deep — and does **not** survive this move.
Both resolve against the source file via `runtime.Caller(0)`, not the working
directory; the phase's original text had that mechanism wrong.

A third path moved with `deploy/`: `devconfig/managed_test.go`'s shipped-template
constant. That is the one that fails **silently** (`t.Skipf`), so it was verified
by running the test and confirming **PASS, not SKIP** — a green suite would have
looked the same either way.

## `init/` is documentation-only, and the copies are real

Six reference units — three launchd plists, three systemd units — **generated by
the actual renderer** (`Spec.LaunchdPlist` / `Spec.SystemdUnit`) with placeholder
values, so they show the true shape rather than a hand-written approximation. Each
carries a banner saying it is illustrative and not loaded, and `README.md` names
`internal/cli/laneservice` as the single authority.

The rationale is the lane-election precedent, not aesthetics: a `go:embed` copy
would be a second store of derivable state with a sync obligation, and its drift
is invisible in exactly the two ways that matter — a plist missing
`StandardErrorPath` logs nowhere, and a stop timeout that stops matching the
shutdown grace gets the daemon SIGKILLed mid-drain on every restart.

**A validation caught a real defect in the banner**: `--shutdown-grace` inside an
XML comment is illegal (a double hyphen ends the comment), so the first plists
were not well-formed XML. All three now parse.
